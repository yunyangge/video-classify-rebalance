# 本地验证记录

2026-11-16，在 macOS 26.6 / arm64、Python 3.12.14 下验证。依赖为 NumPy 2.2.6、PyArrow 25.0.1、DuckDB 1.5.6、SciPy 1.15.3。

| 项目 | 结果 |
|---|---|
| 功能测试 | 29 项通过 |
| 小数据最优结果 | 12 组随机候选池，与全部子集穷举结果一致 |
| 独立进程求解 | 正常返回最优选择；零剩余时间保留已有可行选择 |
| 端到端合成测试 | 2,000 条进入分类，重平衡选出 1,000 条、250 小时；配额、技术指标、平均密度审核通过 |
| HTML | 两阶段页面正常渲染，类目切换正常；六个 JSON 下载结果与磁盘文件一致 |
| 安装包 | wheel 构建及独立目录安装通过，包含统计页模板 |

端到端测试使用确定性编码器替身；类目中心匹配、字段回填、文件读写和重平衡运行实际代码。该测试没有运行真实 Qwen 权重，也不用于衡量 GPU 吞吐或分类准确率。

运行功能测试：

```bash
python -m unittest discover -s tests -v
```

测试覆盖整组 tag 编码、一级节点直接命中、嵌套字段保留、中心文件一致性、高低密度搭配、目标优先级、空名单、缺失字段及导出内容篡改。
