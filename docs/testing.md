## 远程 RTX 5090 验证

2026-11-16，使用真实 Qwen3-Embedding-4B 权重跑通分类和重平衡。被测代码为 `f61fd42`，29 项功能测试在远程全部通过。

| 环境 | 配置 |
|---|---|
| GPU | 单机单张 RTX 5090，显存约 32 GB |
| 系统 | Ubuntu 22.04 环境，Linux 5.15，x86_64；Python 3.10.12 |
| 模型运行时 | PyTorch 2.9.1+cu128、CUDA 12.8、Transformers 5.19.0；BF16 |
| 数据与求解 | NumPy 2.2.6、PyArrow 25.0.1、DuckDB 1.5.6、SciPy 1.15.3 |
| 批量 | batch 128，padding 预算 16,384 tokens，查询/中心长度 512/96 |
| CPU | PyTorch 4 线程，求解器 8 线程 |
| 重平衡预算 | 连续松弛每阶段 10 秒，整数求解总计 60 秒；每大组最多 32 个组合，细化 1 轮 |

测试从已有真实 Meta 中按 URL 哈希选出 20,000 条唯一记录，去除旧分类和分配字段后重新处理。大小字段沿用原有标记的估算值；本轮目标小时设为候选总小时的 50%，类目上下界围绕本批原始分布设置。

| 环节 | 结果 |
|---|---|
| 建立 1,258 个内容中心 | 17.38 秒 |
| 分类完整流程，20,000 条 | 68.23 秒，约 293 条/秒 |
| 其中模型加载 | 2.34 秒；前一环节已经读取过权重 |
| 其中实际查询编码 | 62.85 秒，约 318 条/秒，20,000 次真实模型查询 |
| GPU 显存峰值 | 已分配 8.76 GiB；缓存预留 28.69 GiB |
| 重平衡及审核、导出 | 66.06 秒；7,774 组、39,450 个组合 |
| 最终名单 | 8,959 条，1,023.79 小时；目标 1,024.81 小时，允许偏差 0.1% |
| 结果核验 | 原始字段改动 0；唯一性通过；304 项平均密度检查通过，最高 2.499946 GiB/小时 |

本轮完成了限时求解，部分阶段到时保留已有可行名单。372 项时长/类目检查中还有 149 项存在缺口；输入的 `fps` 和 `asr` 全为空，因此技术要求未全部通过。1080 和 1440 的目标小时均已满足，最终 `passed=false` 与这些缺口一致。

重新编码中心后，与历史结果相比有 728 条内容标签、113 条形态标签不同。另选 512 条样本，固定相同中心和运行参数对比新旧代码，15 个分类字段全部一致；仅切换到重建的中心，部分边界样本就会换类。这些对比用于检查实现一致性，未使用人工标注计算分类准确率。
